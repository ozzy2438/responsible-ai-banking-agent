# Controlled Pilot Readiness Checklist

Every item is required before an accountable executive can make a go/no-go
decision. Repository checks cannot approve these items.

- [ ] Named product, risk, legal, privacy, compliance, security, operations,
      identity, data/API, MRM, and executive owners.
- [ ] Approved OIDC, scopes/ACR, consent/re-authentication, and revocation path.
- [ ] Approved read-only bank API, data classification, policy sources, and
      end-to-end sandbox contract evidence.
- [ ] DPIA/PIA, legal/regulatory review, retention/deletion, notices, and
      cross-border decisions.
- [ ] Hosting/network/secrets/SIEM/on-call design, load test, backups, restore,
      failover, RTO/RPO, and incident exercise.
- [ ] Independent penetration test with all critical/high findings closed and
      retested.
- [ ] Staff UAT, accessibility testing, MRM validation, approved thresholds,
      and change/drift policy.
- [ ] Small named cohort, read-only feature flags, human escalation capacity,
      support scripts, daily review, kill switch, rollback, and exit criteria.
- [ ] Exact candidate commit, digest, SBOM/provenance, configuration inventory,
      and signed go/no-go record.

No money movement, credit/fraud decision, customer-record change, or other
irreversible action is added by this pilot checklist.
